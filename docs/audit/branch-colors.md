# Official service colors (research)

"given" = hex/RGB printed by the source. "converted" = source gave only Pantone (or RGB), hex is the standard sRGB value for it (Pantone's own coated-swatch hex, or RGB converted to hex). Converted values are approximate.

Note: the 2009 guide's hex and RGB columns contradict each other. The word "scarlet" does not appear in the guide; the official name is "Red". Suggested screen use: red #A6192E (standard sRGB for PMS 187C, converted), blue #002B5C (RGB as printed), gold #CC9900 or darker RGB gold #8C7B21 (judgment call).

## Coast Guard
| Color | Hex | Source title | URL | Basis |
|---|---|---|---|---|
| Coast Guard Red (PMS 179 C) | #E03C31 | USCG Trademark and Licensing page | https://www.uscg.mil/Community/trademark/ | converted from Pantone |
| Coast Guard Blue (PMS 307 C) | #006BA6 | same | same | converted from Pantone |

The mark is a tri-band of blue (307 C), white, red (179 C). The USCG branding guidelines PDF (media.defense.gov, 2021) has a Pantone Colors page but no extractable text values. Older Coatings and Color Manual (CG-263) uses Federal Standard 595 chips (blue 15182 about #3085AC, red 12199 about #DA473B), which differ from the Pantone-based values.
